このブログの原文記事は `content/` ディレクトリに、翻訳結果は `i18n/translations/` に置かれ、どちらも Git で管理されます。

## 執筆方法

Hugo や Hexo と同様、各記事は 1 つのディレクトリ（page bundle）で、画像は同じディレクトリに置きます。

```bash
pnpm new my-post --title "我的文章"
```

## 繁簡変換

簡体字の原文からは OpenCC によって繁体字版が自動生成されます。たとえば「软件」「内存」「鼠标」は台湾の用語に変換されます。
手動で指定することもできます。「服务器」とするか、「不转换」を使って元のままにすることもできます。

### コードは変換されません

`内存` のようなインラインコードや、コードブロック内の中国語はそのまま保持されます。
